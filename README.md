# TatarHost Android Launcher

Неофициальный Android-форк открытого ПК-лаунчера [millida/launcher](https://github.com/millida/launcher).

> **Состояние проекта: перенос в разработке. APK пока не готов.** Этот репозиторий сейчас фиксирует архитектуру и план мобильной адаптации; наличие документации не означает, что Java-игры уже запускаются.

## Цель

Сделать мобильный лаунчер для Minecraft: Java Edition с адаптированным интерфейсом ПК-проекта и запуском игры непосредственно на устройстве Android, а не через облачный стриминг.

Планируемые направления: профили и версии Minecraft, автоматическая установка Java, Vanilla, Fabric, Forge, NeoForge и Quilt, моды и модпаки, шейдеры и ресурспаки, миры, серверы, настройки производительности и управление файлами.

Полный список статусов и ограничений — в [FEATURES.md](FEATURES.md). Техническая схема переноса — в [PORTING.md](PORTING.md).

## Архитектура

- **Интерфейс и общая логика:** React/TypeScript из исходного проекта, адаптированные для сенсорного управления и небольших экранов.
- **Ядро лаунчера:** Rust/Tauri 2 с отдельными Android-реализациями функций, которые на ПК используют системные процессы, окна, трей и файловые диалоги.
- **Запуск Minecraft Java:** Android-совместимая JVM и графический слой. В качестве технической основы изучается [Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android), где заявлены мобильные OpenJDK 8/17/21, OpenGL и поддержка Forge/Fabric.
- **Каталоги:** прямые интеграции с публичными источниками там, где это разрешено и технически возможно. Сервисы, принадлежащие Millida, не считаются доступными этому форку.

## Сборка

Инструкция сборки APK будет добавлена после подключения Android-ядра и прохождения CI. Сейчас готового APK в репозитории нет, и ранние тестовые сборки не следует считать полноценным лаунчером.
