# Неофициальный Android-порт исходников Millida Launcher

Этот проект переносит **настоящий исходный код** [millida/launcher](https://github.com/millida/launcher) на Android. Это не отдельный лаунчер на базе Pojav/Amethyst: основной интерфейс берётся из React/TypeScript Millida, а основное ядро — из её Rust/Tauri-кода.

<badge>Android-порт в разработке</badge>

> Релиз `android-prototype-5` был ранней проверкой чужого Android runtime и **не является портом Millida Launcher**. Его не следует считать нужным приложением. Новая линия сборки будет исходить из `millida/launcher`.

## Что переносится

Сохраняются исходный экранный интерфейс и существующие функции Millida: профили, версии, Fabric/Forge/NeoForge/Quilt, загрузка модов и модпаков, настройки, миры, серверы, каталоги и аккаунтные экраны. Для Android нужно адаптировать настольные системные функции, файловый доступ, фоновые задачи, аудио и запуск Java.

## Почему это не одна команда сборки

У исходника есть Tauri mobile entry point и Android-иконки, но игровые процессы реализованы для настольной ОС. Android не запускает обычный desktop Java runtime тем же способом: нужен Android JVM через JNI и совместимый LWJGL/OpenGL backend. Также недоступны некоторые настольные возможности: трей, глобальные горячие клавиши, второе окно-оверлей и desktop updater. Их нужно заменить мобильными реализациями или скрыть только там, где эквивалента действительно нет.

## Бренд, лицензии и сервисы

Код исходного проекта распространяется под GPL-3.0-only. Правила самого проекта отдельно запрещают публиковать форк под названием/логотипом Millida без разрешения; допустимо фактически указывать, что это неофициальный форк, основанный на Millida Launcher. Поэтому публичная сборка должна иметь собственный package ID и отличимое название/иконку, при этом использовать именно исходный код и интерфейс Millida.

Закрытые ключи, подпись приложения, Microsoft/Discord app IDs и официальные updater credentials не копируются. Некоторые сервисы Millida могут блокировать неофициальные сборки; их доступность нельзя обещать.
