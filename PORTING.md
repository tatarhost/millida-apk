# План переноса ПК-лаунчера на Android

## Зафиксированные исходные версии

- ПК-источник: `millida/launcher`, ветка `main`, проверенный коммит `a9cec042ad1515a495a4f7c550e71f7423b65812` (2026-11-05).
- Android runtime reference: `AngelAuraMC/Amethyst-Android`, ветка `v3_openjdk`, проверенный коммит `28d6e12d68121b7dd75f2e841058a6b7cdfe4a29` (2026-10-26).
- Репозиторий этого форка: `tatarhost/millida-apk`, ветка `main`.

Это зафиксированные точки исследования, а не готовая объединённая сборка.

## Почему нельзя просто собрать ПК-проект как APK

ПК-приложение использует Tauri 2, React и Rust. Tauri умеет собирать Android APK, но это решает только доставку интерфейса и Rust-кода в Android-приложение. ПК-часть лаунчера также обращается к системным процессам, системным каталогам Java, окнам, трею, глобальным клавишам и настольным диалогам.

Minecraft Java на Android требует отдельной совместимой JVM, нативных библиотек и графического слоя. Обычный Linux JRE из настольной сборки не является заменой Android JVM. Android runtime должен уметь запускать JVM внутри Android-процесса и предоставлять Minecraft подходящие LWJGL/OpenGL реализации.

## Целевая схема

1. **Мобильная оболочка.** Оставить React-интерфейс и общие модели данных, сделать сенсорную навигацию, компактные панели, системный выбор файлов Android, обработку поворота и возврата.
2. **Android-адаптер ядра.** Разделить настольные и мобильные модули через платформенные реализации. Убрать из Android-сборки трей, overlay-окна, автозапуск ПК, desktop updater и системные команды, для которых нет безопасного Android-эквивалента.
3. **Исполнение Java.** Подключить Android-совместимые JVM/runtime и графические библиотеки. Игровая сессия должна запускаться в отдельном Android Activity/поверхности с сенсорными контролами и поддержкой геймпада.
4. **Установка Minecraft.** Сохранить общие алгоритмы получения метаданных, загрузки и проверки файлов; отдельно реализовать Android-совместимые нативные зависимости и пути. Не подменять Android JVM обычной Linux Java.
5. **Загрузчики и контент.** Перенести и проверить Vanilla, Fabric, Forge, NeoForge и Quilt отдельно по версиям игры. Добавить загрузку модов, ресурспаков, шейдеров и импорт ZIP/MRPACK. Совместимость конкретного мода или шейдера зависит от версии, загрузчика, рендерера и устройства.
6. **Сервисы.** Заменить или отключить вызовы серверов Millida. Собственные аккаунты, синхронизация, друзья, скины, голос, хостинг и серверный прокси требуют своих API и инфраструктуры; их нельзя включить одной настройкой.

## Зависимости и лицензии

- ПК-код: GPL-3.0-only. При распространении производной сборки необходимо соблюдать GPL, сохранять уведомления, явно отмечать изменения и предоставлять соответствующий исходный код.
- Amethyst/Pojav-derived Android runtime: LGPL-3.0 в проверенной ветке Amethyst. Его компоненты и нативные зависимости имеют отдельные лицензии; перед релизом нужен аудит NOTICE и условий каждой библиотеки.
- Нельзя переносить фирменные логотипы, плащи, ключи подписи, updater endpoint и другие брендовые ресурсы Millida. В Android package name, имя приложения, иконки и updater должны быть собственными.
- Не использовать опубликованные в чужом репозитории keystore/debug signing files. Для собственного релиза создаётся собственная подпись; секреты хранятся только в GitHub Actions Secrets.

## Критерии готовности

- [ ] Android ARM64 debug APK собирается в GitHub Actions и прикрепляется как artifact.
- [ ] APK устанавливается и открывает мобильный интерфейс без сетевых сервисов Millida.
- [ ] Vanilla запускается на устройстве с правильной JVM для выбранной версии.
- [ ] Fabric и Forge отдельно устанавливаются и реально запускают тестовые сборки.
- [ ] NeoForge и Quilt проверены на поддерживаемых сочетаниях версий.
- [ ] Импорт ZIP/MRPACK, установка и удаление модов работают на Android-хранилище.
- [ ] Шейдеры проверены на конкретных мобильных рендерерах; несовместимые варианты явно помечаются.
- [ ] Проверены сенсорное управление, клавиатура, мышь, геймпад, звук, поворот экрана, пауза и возврат из игры.
- [ ] В сборке нет Millida updater, приватных ключей или вызовов закрытых сервисов без разрешения.
