# Матрица переноса функций

Статус всех функций ниже — **не перенесено и не проверено на Android**, пока это явно не изменено после тестов. Список отражает возможности ПК-источника и план переноса, а не обещание совместимости каждого мода/шейдера.

| Область | ПК-проект | Цель Android | Примечание |
|---|---|---|---|
| Версии Minecraft | Есть | Запуск Vanilla | Нужна Android JVM и нативная среда |
| Java runtime | Установка desktop JRE | Android OpenJDK | Нужны отдельные Android builds JVM |
| Fabric | Есть | Перенос | Проверять по версии Minecraft |
| Forge | Есть | Перенос | Не все старые/новые сочетания одинаково работают |
| NeoForge | Есть | Перенос | Требует отдельной проверки на Android |
| Quilt | Есть | Перенос | Требует отдельной проверки на Android |
| Моды | Modrinth/CurseForge и локальные файлы | Каталог + JAR/ZIP импорт | Совместимость определяется модом и загрузчиком |
| Модпаки | Установка/импорт/обновления | ZIP/MRPACK | Нужна адаптация путей и распаковки |
| Шейдеры | Менеджер и профили | Совместимые shader packs | Зависит от OpenGL backend/GPU |
| Ресурспаки | Профили/файлы | Импорт и переключение | Проверить UI и игровые настройки |
| Миры | Список, резервные копии, импорт/экспорт | Android storage | Нужен SAF-доступ |
| Серверы | Список и быстрый вход | Перенос | DNS/SRV и сетевые ограничения Android |
| Профили | Создание и запуск | Перенос | Хранение в private app storage |
| Аккаунт Microsoft | Вход через ПК-поток | Новый OAuth redirect | Требуется собственный Azure app registration |
| Оффлайн-профиль | Есть | Перенос | Не даёт лицензию или доступ к платным функциям |
| Скины/плащи | В том числе Millida services | Нужен собственный сервис или локальная замена | Закрытые API Millida не включаются |
| Друзья/чат/голос | Millida services | Нужен собственный backend | Не работает от одного переноса интерфейса |
| Хостинг/социальные функции | Millida services | Отдельный проект backend | Не включать чужие сервисы без разрешения |
| Производительность | Desktop GPU/Java tuning | Android GPU/thermal/RAM | Нужны отдельные мобильные профили |
| Внутриигровой overlay | Desktop overlay window | Android overlay/controls | Нельзя считать desktop-окно Android-эквивалентом |
| Обновление приложения | Desktop updater | Android installer/update flow | Нужны собственные endpoint и подпись |
| Голос/медиа | Desktop devices | Android permissions/APIs | Требует отдельной реализации |

## Правило отметки готовности

Функция считается перенесённой только после сборки APK и проверки на Android устройстве или эмуляторе соответствующего типа. Компиляция общего кода, появление кнопки в интерфейсе или успешная загрузка мода сами по себе не означают, что Java-игра запускается.
